ABSTRACT 
The Online Medicine App is a Flutter-based mobile and web application designed to provide 
a convenient platform for browsing and purchasing medicines online. The application allows 
users to register and log in securely, browse medicines by category, search for products, view 
individual medicine details, select quantities, add products to a cart and proceed with 
checkout. 
Firebase is used as the backend platform. Firebase Authentication provides email/password 
authentication and account-related functions, while Cloud Firestore stores user information, 
delivery addresses and order information. Firebase Storage is used to store user profile 
photos, with the resulting download URL stored in the corresponding user document. 
The application supports both cart-based checkout and Buy Now checkout. Users can manage 
delivery addresses, view order history and manage their profile. An admin order screen 
allows the specified administrator to view customer orders and update order statuses such as 
Pending, Confirmed, On the Way, Delivered and Cancelled. The application also includes an 
AI Assistant screen. 
The project demonstrates how Flutter and Firebase can be combined to develop a responsive 
online medicine shopping application with persistent user, profile, address and order data.

CHAPTER 1 – INTRODUCTION 
The Online Medicine App is a digital medicine shopping application developed using Flutter 
and Dart. The main purpose of the application is to provide users with a simple interface 
through which they can browse medicines, search for required products, view detailed 
medicine information, add medicines to a cart and place orders. 
The application is designed for mobile and web use. Firebase services provide the backend 
support required for user authentication, persistent data storage and profile image storage. 
This allows important user and order information to remain available across sessions. 
The application contains separate user and administrator functionality. Users can manage 
their profile, addresses and orders, while the administrator can view customer orders and 
update order status. The application also contains an AI Assistant screen to support the 
overall user experience. 
1.1 Project Overview 
The system maintains a medicine database containing around 50 products. Each medicine 
includes a name, price, category, image and an individual description. Categories include 
Tablets, Antibiotics, Diabetes, Supplements, Syrups, Injections, Gels, Ointments, Sprays, 
First Aid, Eye Care, Ear Care and Nutrition. 
1.2 Need for the Project 
Traditional medicine purchasing may require users to physically visit a store and search for 
available products. A digital platform can organize medicine information and provide a 
structured shopping process. The proposed application focuses on product discovery, cart 
management, checkout, address management and persistent order history. 
1.3 Project Scope 
The project covers the development of the application interface, Firebase authentication, 
Firestore-based data persistence, Firebase Storage for profile photos, medicine search and 
browsing, cart management, checkout, order history, address management, profile 
management and administrator order management. 
CHAPTER 2 – PROBLEM STATEMENT 
Users need a convenient way to browse medicine products, compare available information, 
manage quantities and place orders without depending on temporary local application data. A 
system is required to securely manage user accounts, retain delivery addresses and maintain 
order records. 
The project therefore addresses the problem of creating a centralized Flutter application that 
connects medicine browsing and purchasing functions with a persistent Firebase backend.

class CartManager { 
  static final List<CartItem> cartItems = []; 
 
  static void addItem(String name, double price, int quantity) { 
    // Check if medicine already exists 
    for (var item in cartItems) { 
      if (item.name == name) { 
        item.quantity += quantity; 
        return; 
      } 
    } 
 
    // Add new medicine 
    cartItems.add(CartItem(name: name, price: price, quantity: quantity)); 
  } 
 
  static void removeItem(CartItem item) { 
    cartItems.remove(item); 
  } 
 
  static double getTotalPrice() { 
    double total = 0; 
 
    for (var item in cartItems) { 
      total += item.price * item.quantity; 
    } 
 
    return total; 
  } 
 
  static void clearCart() { 
    cartItems.clear(); 
  } 
}

used for managing user registration and login activities. Cloud Firestore is used to store 
application data such as user details, medicine information, cart details, and order records. 
Firebase Storage is used for storing user profile images. 
The Flutter application is connected with Firebase using Firebase Core configuration. The 
integration enables real-time data communication between the mobile application and 
Firebase services.

CHAPTER 15 – RESULTS 
The implemented application provides the major workflows required for an online medicine 
shopping system. Users can authenticate, browse and search medicine products, view 
individual product information, manage a cart, complete checkout, save delivery addresses, 
manage their profiles and access persistent order history. 
The Firebase integration provides persistent storage for user, address and order information. 
Profile photos are uploaded to Firebase Storage and their download URLs are stored in 
Firestore. The administrator can view orders and update their status. 
The application is designed for Android and Flutter Web, allowing the same Flutter project 
structure to be used across the supported platforms. 
CHAPTER 16 – ADVANTAGES 
• Simple and organized medicine browsing experience. 
• Search facility for locating medicines quickly. 
• Individual medicine descriptions improve product information. 
• Cart supports multiple products and quantity management. 
• Buy Now provides a direct purchase flow. 
• Firebase provides persistent authentication and data storage. 
• Order history allows users to review previous orders. 
• Saved addresses simplify delivery information management. 
• Profile photos remain available after logout/login. 
• Admin order status management provides order tracking information. 
• Flutter supports Android and Web from a common codebase.

CHAPTER 17 – LIMITATIONS 
• The application depends on internet connectivity for Firebase-based operations. 
• The medicine database is currently a fixed project dataset of around 50 products. 
• The application does not establish real-world medicine inventory verification. 
• Payment processing functionality is represented through the checkout payment-method 
flow rather than a confirmed real-world payment gateway implementation. 
• Delivery logistics and real-time geographical tracking are outside the implemented scope.
